# Privacy Policy — Rohit Creative Slash Menu

Last updated: August 23, 2026

Rohit Creative Slash Menu is a browser extension that adds a creative-design slash command menu to supported ChatGPT pages.

## Data collected
The extension does not collect, sell, transmit, or store personal information, conversation content, uploaded files, browsing history, passwords, payment information, or account credentials.

## Local storage
The extension uses Chrome's local extension storage only to cache its command library and the last synchronization time. This information remains on the user's device unless Chrome itself synchronizes browser data according to the user's browser settings.

## Network access
The extension may request a public JSON command library from a GitHub-hosted raw file. The purpose of this request is to update command names, descriptions, categories, and prompt presets. No ChatGPT conversation content or personal information is included in this request.

## Permissions
The extension requests only the permissions required for its features, including local storage, alarms for periodic synchronization, access to the public command-library host, and content-script access on supported ChatGPT domains.

## Third-party services
The extension operates on ChatGPT pages but is not affiliated with, endorsed by, or an official product of OpenAI. The extension's use of ChatGPT remains subject to OpenAI's own terms and privacy policies.

## Changes
This privacy policy may be updated if the extension's functionality or data practices change. Material changes will be reflected in this document.

## Contact
For privacy questions or support, use the GitHub repository associated with this extension.
